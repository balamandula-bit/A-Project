# Classic Snake Game

## Classic Snake

### Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser (or open `index.html` directly if you prefer a file URL).

### Controls

- Arrow keys or W/A/S/D to move.
- Space or P to pause.
- Use the on-screen D-pad buttons on mobile.

### Manual checklist

- Start the game, confirm the snake moves and grows when eating food.
- Verify collisions with walls or the snake end the game.
- Pause/resume and restart work as expected.
